Context:
Selecting a tract selects a community.
(If the tract has more than one community,
the user picks just one in a popup window.)

  • If “Include all community-sharing tracts” is checked:

The map will show all tracts that share the selected community.
Those tracts may contain sections of other communities.
Therefore the data plotted for this community may INCLUDE some data from neighboring communities.


  • If “Include all community-sharing tracts” is NOT checked:

The map will show ONLY tracts with only the selected community.
Therefore the data plotted for this community may EXCLUDE some of this community’s data from neighboring tracts.
(If there are no such tracts, a warning is issued and the toggle reverts.)
