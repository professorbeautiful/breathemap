Context:
Selecting a tract selects a community.
(If the tract has more than one community,
the user picks just one in a popup window.)

 * If “Include all community-sharing tracts”
   is checked:

The map will show ALL tracts that share the selected community.
(If tracts contain sections of other communities,
the data plotted for this community may INCLUDE some data from neighboring communities.)


 * If “Include all community-sharing tracts”
   is NOT checked:

The map will show ONLY the tracts with ONLY the selected community.
Therefore the data plotted for this community might EXCLUDE some of this community’s data from neighboring tracts.
(If there are no such tracts, a warning is issued and the toggle reverts.)
